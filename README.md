# Frame Bucket

Frame Bucket is a taxonomy-driven AI web design generator. Users build a design recipe from visual, layout, interaction, and system buckets, then generate a single self-contained HTML page from that recipe.

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open `http://localhost:3000`.

## Scripts

```bash
pnpm lint
pnpm test
pnpm typecheck
pnpm build
```

## Environment

Copy `.env.example` to `.env.local` and fill the real values before working on Notion sync or Anthropic generation.
